# Orrery

This demo was created in the span of 60 hours for the 2024 [NASA Space Apps Challenge](https://www.spaceappschallenge.org/), by Calvin Crady and Newt Powers. Although not feature-complete, we managed to create a minimum viable product, with graphics, mouse controls, and accurate astronomical positioning of the Solar System's planets.

[You can see the demo online here.](https://ccrady.github.io/orrery/app.html)
